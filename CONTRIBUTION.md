# Contribution and Dependency Boundary

## Personally led work
- ROS2 experiment environment setup and repeated robot testing
- Cartographer/Nav2-based driving environment configuration and integration
- Node / Topic / Message tracing
- LiDAR ROI and target-selection experiments
- Distance / target-motion / closing-speed logic
- Ego-motion coordinate compensation
- Spatial/temporal filtering
- TTC computation and spatial activation logic
- STOP/KEEP velocity-filter integration
- Command-topic architecture changes
- Troubleshooting and root-cause analysis
- Experiment design, execution, CSV logging and graph analysis
- Paper and poster preparation

## Coauthor role
A coauthor assisted with experimental operation, including operating the opposing robot. The project should not be described as every experiment and every robot operation being performed alone.

## Existing packages / upstream software
- Cartographer
- Nav2
- AMCL
- robot_localization
- DWB / MPPI controller plugins
- LiMO vehicle drivers

These were used/configured/integrated; they were not authored from scratch in this project.

## Generative AI
Generative AI was used for parts of Python/ROS code drafting and modification. The portfolio claim is therefore centered on problem definition, architecture decisions, code application/modification, parameter selection, experiments, debugging, and validation rather than claiming every line was handwritten from scratch.
